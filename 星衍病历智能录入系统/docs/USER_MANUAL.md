## 系统简介

星衍AI智能病历录入系统是一款基于人工智能的医疗病历录入工具，通过语音识别技术实现快速、准确的病历录入。

### 核心功能

- 🎤 **语音识别**：边说边出字，实时预览
- 🧠 **智能填充**：自动识别字段，结构化填充
- 📚 **知识图谱**：27,947个医学实体，535,803条关系
- ⚖️ **法律知识**：医师法、医疗事故处理条例等
- 📝 **模板系统**：71个病历模板，覆盖内/外/妇/儿/中医
- ✨ **智能纠错**：医学专业词汇纠错
- 🔄 **多轮录音**：分段录入，不覆盖已填内容

### 系统要求

- 麦克风（必需）
- 现代浏览器（Chrome/Firefox/Safari/Edge）
- 8GB+ 内存

## 快速入门

### 启动系统

#### 方式一：桌面应用

```bash
# 启动WebView版（推荐）
python main.py

# 或启动PyQt5原生版
python main.py --legacy
```

#### 方式二：Web服务

```bash
python app_server.py
```

然后在浏览器访问：`http://localhost:8765`

### 首次使用

1. **选择科室**：在工具栏选择科室（内科/外科/妇产科/儿科）
2. **选择模板**：选择病历模板（如"入院记录"）
3. **开始录音**：点击"🎤 开始录音"或按 F2
4. **说话录入**：对着麦克风说出病历内容
5. **确认结果**：查看预览，点击"✓ 接受"或"✗ 拒绝"

## 语音录入

### 基本操作

#### 开始录音

- 点击工具栏"🎤 开始录音"按钮
- 或按快捷键 `F2` / `Ctrl+R`
- 或说语音命令"开始录音"

#### 停止录音

- 点击"⏹ 停止录音"按钮
- 或按 `F2`
- 或说"停止录音"
- 或等待自动停止（根据录音模式）

#### 录音模式

- **手动停止**：手动点击停止（推荐）
- **连续录音（60s）**：60秒后自动停止
- **连续录音（120s）**：120秒后自动停止

### 语音预览

录音时，系统会实时显示识别结果：

1. **流式预览**：边说边出字，实时显示
2. **最终确认**：录音结束后显示完整结果
3. **操作选项**：
   - ✓ **接受**：将识别结果填入病历
   - ✗ **拒绝**：丢弃本次识别结果
   - ↻ **重听**：重新开始录音

### 智能填充

系统会自动识别语音内容并填充到对应字段：

**示例1：带字段标记**
```
你说："主诉发热三天"
系统填充：主诉：发热三天
```

**示例2：不带字段标记**
```
你说："发热三天，伴有咳嗽"
系统智能判断：主诉：发热三天，伴有咳嗽
```

**示例3：多字段**
```
你说："主诉发热三天，现病史三天前受凉后出现发热"
系统填充：
  主诉：发热三天
  现病史：三天前受凉后出现发热
```

### 多轮录音

系统支持多次录音，不会覆盖已填内容：

**第1次录音**：
```
你说："发热三天"
结果：主诉：发热三天
```

**第2次录音**：
```
你说："三天前受凉后出现发热"
结果：
  主诉：发热三天（保持不变）
  现病史：三天前受凉后出现发热（新增）
```

### 语音命令

系统支持以下语音命令：

| 命令 | 功能 |

| "开始录音" | 开始录音 |

| "保存病历" | 保存当前病历 |
| "打开病历库" | 打开病历库 |
| "换模板XX" | 切换到XX模板 |

## 模板管理

### 选择模板

1. 在工具栏"模板"下拉框中选择模板
2. 或在输入框中搜索模板名称
3. 系统自动加载模板内容

### 可用模板

**内科**（22个）：
- 入院记录
- 首次病程记录
- 日常病程记录
- 出院记录
- ...

**外科**（21个）：
- 入院记录
- 手术记录
- 术后病程记录
- ...

**妇产科**（14个）：
- 入院记录
- 分娩记录
- 产后病程记录
- ...

**儿科**（14个）：
- 入院记录
- 新生儿记录
- ...

**中医**（各5个）：
- 内科-中医
- 外科-中医
- 妇产科-中医
- 儿科-中医

### 一键套用

对于含占位符的模板（如"发热X天"），可以：

1. 选择模板
2. 点击"⚡ 一键套用"
3. 说出核心信息
4. 系统自动替换占位符

**示例**：
```
模板：发热X天，伴有X
你说："发热三天，伴有咳嗽"
结果：发热三天，伴有咳嗽
```

### 模板管理

点击"📝 模板管理"可以：
- 查看模板列表

- 删除模板

## 知识问答

### 打开问答面板

- 点击工具栏"📚 知识问答"按钮
- 或按快捷键（如有配置）

### 提问方式

在输入框中输入问题，例如：

**疾病查询**：
```
高血压的常见治疗方案
```

**药物查询**：
```
阿莫西林的说明书
```

**法律查询**：
```
医疗事故怎么鉴定
```

**案例查询**：
```
李建雪案
```

### 回答类型

系统支持以下类型的回答：

1. **疾病治疗**：治疗方案、常用药物
2. **药物说明**：适应症、用法用量、禁忌
3. **检查建议**：建议做的检查项目
4. **症状分析**：常见症状、可能疾病
5. **中医辨证**：证型、治法、方药
6. **饮食宜忌**：宜吃、忌吃、食谱
7. **法律条文**：医师法、医疗事故处理条例
8. **案例解读**：经典医疗事故案例

### 快捷追问

回答后会显示快捷追问建议，点击即可追问。

### 链接点击

回答中的疾病、药物、检查等实体可以点击查看详情。

## 高级功能

### 字段常用词

每个字段都有常用词面板，点击即可插入：

1. 在编辑器中点击对应字段
2. 右侧显示该字段的常用词
3. 点击词语插入到光标位置

### 常用语句库

按 `F3` 打开常用语句库：

1. 选择字段
2. 查看常用语句
3. 点击插入
4. 可以添加自定义语句

### 智能纠错

系统会自动纠正常见医学词汇错误：

```
你说："心电围"
系统纠正为："心电图"
```

### 音文对照回放

系统会保留录音文件，可以回放校对：

1. 录音完成后，右侧显示播放器
2. 点击播放按钮回放录音
3. 对照文本检查识别结果

### 纠错反馈

对识别结果进行纠错后，系统会学习：

1. 点击"✨ 纠错"
2. 修改错误词汇
3. 系统记录纠错反馈
4. 下次识别时自动纠正

### 数据备份

系统每天自动备份数据库到 `data/backups/` 目录。

手动备份：
```bash
cp data/records.db data/backups/records_$(date +%Y%m%d).db
```

## 常见问题

### Q1: 麦克风无法使用

**解决**：
1. 检查麦克风是否连接
2. macOS：系统偏好设置 → 安全性与隐私 → 麦克风 → 允许
3. Linux：检查设备权限 `sudo usermod -a -G audio $USER`
4. Windows：设备管理器检查驱动

### Q2: 识别不准确

**解决**：
1. 确保环境安静
2. 说话清晰、语速适中
3. 使用高质量麦克风
4. 在"麦克风"下拉框选择正确的设备
5. 启用"录音降噪"选项

### Q3: 模型加载失败

**解决**：
```bash
# 清除缓存重新下载
rm -rf ~/.cache/modelscope/
python -c "from asr_engine import ASREngine; ASREngine()"
```

### Q4: 系统启动慢

**解决**：
1. 首次启动需要下载模型（约1GB），请耐心等待
2. 后续启动会快很多
3. 如果仍然慢，检查网络连接

### Q5: 内存不足

**解决**：
1. 关闭其他占用内存的程序
2. 增加系统内存
3. 增加swap空间（Linux）：
```bash
sudo fallocate -l 4G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
```

### Q6: 数据库锁定

**解决**：
```bash
# 关闭所有连接
pkill -f app_server.py

# 清理锁文件
rm -f data/records.db-journal
```

### Q7: 如何备份数据

**解决**：
```bash
# 备份数据库
cp data/records.db data/backups/records_$(date +%Y%m%d).db

# 备份配置
tar -czf config_backup.tar.gz hotwords.txt field_words.json templates/
```

### Q8: 如何恢复数据

**解决**：
```bash
# 恢复数据库
cp data/backups/records_20260815.db data/records.db

# 恢复配置
tar -xzf config_backup.tar.gz
```

### Q9: 支持哪些语言

**当前版本**：仅支持中文普通话

**未来计划**：
- 支持方言（粤语、四川话等）
- 支持英文医学术语
