# 星衍AI智能病历录入系统 v1.0

**内外科专版 — 离线语音识别 + 医疗术语自动纠错 + 科室模板管理**

- 纯本地运行，无需联网
- 基于 FunASR SenseVoice 离线语音识别引擎
- 内置医疗词库 + 三级纠错架构
- 支持内科/外科模板快速填充

---

## 环境要求

- Windows 7/8/10/11
- Python 3.8 或更高版本
- 麦克风（普通耳麦即可）
- 安静环境（诊室/办公室）

## 安装步骤

### 第一步：安装 Python

如果还没装 Python：
1. 访问 https://www.python.org/downloads/
2. 下载 Python 3.8+（推荐 3.11）
3. 安装时勾选 **"Add Python to PATH"**

### 第二步：下载语音识别模型

1. 访问 https://alphacephei.com/vosk/models
2. 下载中文模型（安静环境推荐小的）：
   - **vosk-model-small-cn-0.22.zip**（约 40MB，推荐）
   - 或 vosk-model-cn-0.22.zip（约 1.8GB，准确率更高）
3. 解压后把文件夹重命名为 `model`
4. 把 `model` 文件夹放到 `星衍病历智能录入系统` 目录下

最终目录结构：
```
星衍病历智能录入系统/
├── model/              ← 语音模型（下载的）
├── medical_dict.json   ← 医疗词库
├── templates/          ← 科室模板
├── corrector.py        ← 纠错引擎
├── asr_engine.py       ← 语音识别
├── template_engine.py  ← 模板管理
├── main.py             ← 主程序
├── requirements.txt    ← 依赖
└── 启动.bat            ← Windows 一键启动
```

### 第三步：安装依赖

双击 `启动.bat`，脚本会自动安装所需依赖。

或者手动执行：
```bash
pip install -r requirements.txt
```

### 第四步：运行

双击 `启动.bat` 或在命令行执行：
```bash
cd 星衍病历智能录入系统
python main.py
```

## 使用流程

1. **选择科室** — 顶部下拉框，如"内科""外科"
2. **选择模板** — 如"入院记录""病程记录""手术记录"
3. **开始录音** — 点击"🎤 开始录音"，对着麦克风说话
4. **自动纠错** — 点击"✨ 纠错"，系统自动修正医疗术语
5. **导出保存** — 点击"💾 导出"，保存为 txt/md 文件

## 功能说明

### 语音识别
- 离线实时识别，无需网络
- 中文医疗领域优化
- 支持自定义词库提升准确率

### 三级纠错

| 层级 | 类型 | 说明 |
|------|------|------|
| Layer 1 | 词典匹配 | 医疗术语模糊匹配纠错 |
| Layer 2 | 规则引擎 | 常见口误、单位、格式修正 |
| Layer 3 | 科室校验 | 必填项检查、措辞规范 |

### 科室模板
- 内科：入院记录、首次病程、首页病程、日常病程、出院记录
- 外科：术前记录、手术记录、术后病程、首页病程
- 支持自定义模板（编辑对应科室的 JSON 文件）
- 模板自动加载对应科室词库

## 自定义扩展

### 添加新科室

编辑 `medical_dict.json`，添加新的科室词库：

```json
{
  "新科室": {
    "扩展症状": ["症状1", "症状2"],
    "扩展诊断": ["诊断1", "诊断2"],
    "扩展检查": ["检查1", "检查2"],
    "模板要求字段": ["字段1", "字段2"]
  }
}
```

### 添加纠错规则

在 `corrector.py` 的 `error_patterns` 列表中添加：

```python
(self, r'错误模式', '正确写法'),
```

### 添加模板

在软件内选择科室后，直接编辑模板内容后保存即可。
或手动编辑 `templates/科室名.json` 文件。
